# Bengali-NLP-Safety-Challenge-2026
This repository contains the official codebase and experimental notebooks for the Bengali NLP Safety Challenge 2026 Kaggle competition. It is organized into `Main_Submitted_File/` for the final competition submission pipeline and `experiments/` for model iterations (v7–v17) using BanglaBERT, MuRIL, XLM-RoBERTa, focal loss, and ensembling.
